# Syahrul Irfan, Product Manager

Personal portfolio: case studies for UNTUKU DENTAL, Villa AR Bali, Fajar Bahari, DMS+ Android TV, and MediEase.

Static site, no build step. HTML, CSS, and vanilla JavaScript; English by default with an Indonesian toggle.

## Run locally

```bash
python -m http.server 5173
```

Then open http://127.0.0.1:5173.

## Structure

- `index.html`: page markup and static copy
- `style.css`: layout, type, and motion
- `main.js`: project data (EN/ID), case study dialog, hover preview, language toggle
- `assets/img/`: WebP screenshots (`-sm` files are list thumbnails)

Fonts: Bricolage Grotesque and Instrument Sans (SIL Open Font License), served by Google Fonts.
